# Compose Lab / 拼图暗房

一个在浏览器本地运行的 React 图片组合工作台：将多张图片排列成一张大图，并以尽量少的画质损失导出。

## 开发

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 当前能力

- 网格、横向、纵向排列
- 拖拽调整图片顺序
- 图片边框、圆角、阴影和画布背景
- 按上传顺序、文件名或图片尺寸排序
- PNG、JPG、WEBP 导出
- 原图、2K、4K、社交媒体尺寸预设
- 本地处理，不上传图片

后续功能规划见 [ROADMAP.md](./ROADMAP.md)。
